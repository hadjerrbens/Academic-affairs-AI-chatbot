## The rules (file 2)

**`calculate_gpa(courses, points_map, repeat_policy="BEST") -> (gpa, credits_earned, credits_attempted)`**
**The only GPA function in the project.** Quality points ÷ attempted credits. `F` counts as attempted, not earned. `I`/`W` count in neither. A repeated course counts once for credits and once for GPA (the `BEST` attempt). Zero attempted credits → `(0.0, 0, 0)`, never a divide-by-zero.

**`evaluate_group` by type:** `REQUIRED` — every listed course passed (`grade_points >= passing_points`); `ELECTIVE` — at least N from the pool; `CREDITS` — at least N credits from the pool. A course satisfies **one** group only (no double counting).

**`audit_program`:** `percent_complete = min(1.0, earned/required)`; `eligible_to_graduate` only if **every** group is satisfied **and** GPA ≥ minimum **and** credits ≥ required; `next_actions` ordered most-blocking first.

**`classify_standing(gpa, policy)`** — four statuses only in the MVP: `GOOD_STANDING`, `WARNING`, `PROBATION`, `DISMISSAL`, from three thresholds in `standing_policies.csv`. The appeal deadline is `today + appeal_window_days`; `today` is passed in.

**`format_audit_summary`** — one text block with every number the answer needs (GPA, credits earned/required, missing courses).
