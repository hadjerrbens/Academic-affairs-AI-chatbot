# Degree requirements

Each program defines the courses and credits students must complete. REQUIRED groups need every listed course; ELECTIVE groups need a minimum number of courses from a pool; CREDITS groups need a minimum number of credits from a pool. A passed course may satisfy only one group. The program's graduation GPA and credit requirements are read from the approved program data, not from this document.

A student can ask the chatbot which groups remain incomplete. Current enrollments do not count as completed courses.
